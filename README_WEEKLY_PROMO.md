# Sapiver Forge weekly content kit

The weekly system now supports the Sapiver Forge 12-month execution plan rather than acting as a seven-advert video factory.

## What one run creates

- seven useful daily content items for practical small-business AI decisions;
- seven short spoken scripts suitable for manual phone recording;
- TikTok captions;
- YouTube Shorts titles and descriptions;
- Facebook copy;
- `weekly-content-kit.md` for easy copy/paste use;
- `human-review.html` for reviewing the full week in one place;
- structured `weekly-pack.json` for later reuse.

## Commercial alignment

The current core loop is:

1. publish useful organic content;
2. send people primarily to the free Sapiver Forge Notion workspace;
3. measure genuine Kit subscribers, clicks, questions and sales;
4. promote one active paid product — the complete Applied AI Gate System bundle;
5. review the evidence and improve the clearest bottleneck.

Each generated week therefore contains six free-workspace/list-growth routes and exactly one direct paid-bundle promotion.

## Cost and media rules

This workflow does **not** generate MP3s or MP4s, does not call ElevenLabs, does not call an AI API, and does not create paid media. The content is assembled locally from maintained Sapiver Forge content banks and rotates between runs.

Video remains optional and manual. The generated short scripts are there to make manual phone recording straightforward.

## GitHub Actions

Run **Generate Sapiver Forge Weekly Content Kit** from the Actions tab whenever a fresh kit is needed. A weekly scheduled run is also included. Download the resulting `sapiver-forge-weekly-content-*` artifact and open `weekly-content-kit.md` or `human-review.html`.

Human review remains required before publishing.
