# Sapiver Forge weekly promotional media system

One weekly run creates seven Sapiver Forge promotional scripts, seven narration MP3s, seven vertical MP4s, TikTok captions, YouTube metadata and one human-review file. It uses fixed approved product facts: no news, Exa, Gemini, article, feature, podcast, AI images, Pinterest or LinkedIn.

Review `human-review.html`, then run `Approve Sapiver Forge Weekly Promo Pack` with the exact candidate ID. The approved queue uploads one YouTube Short daily. TikTok remains manual using the supplied MP4 and caption.

Only seven ElevenLabs narration calls are paid. FFmpeg video rendering and all text generation are local.
