What actually happens when you use software?

A 5–10 minute foundation lesson in computing and AI literacy.

Uses your browser or device's built-in text-to-speech where available.
Core mental model:
hardware → operating system → application → data → network/server

1. Hardware

Hardware is the physical equipment inside a computer or phone.

Examples include the processor, memory, storage, screen, cameras and network hardware.

The CPU executes instructions. RAM temporarily holds information a program is actively using. Storage keeps information after the device is switched off.

A useful simplification: RAM is the workbench; storage is the cupboard.

2. Operating system

The operating system, or OS, manages the device and provides services to applications.

Examples include Android, Windows, macOS, Linux and iOS.

When an app wants to use the camera, save a file, display something or access the internet, it normally goes through services provided by the operating system rather than controlling the hardware directly.

3. Applications and code

An application is software designed to perform a task.

Examples include Chrome, Spotify, ChatGPT, a calculator, an Android app or a website running in your browser.

Applications are built from instructions expressed as code.

This is why files such as .py, .js, .html, .apk and .exe are not interchangeable: they represent different kinds or forms of software.

4. Data

Code describes what a system should do. Data is information the system stores, receives or operates on.

If a notes app contains instructions saying “save the user's note”, those instructions are code. The words “buy compost on Saturday” are data.

AI systems may operate on text, photographs, audio, databases, JSON, spreadsheets and many other forms of data.

5. Local and remote computing

If your own device performs the work, the processing is local.

If your device sends a request across a network to another computer that performs the work, that other computer is commonly acting as a server.

6. What people mean by “the cloud”

At a basic level, cloud computing means using computing resources running on infrastructure somewhere else and accessing them through a network.

Those machines still exist physically. They normally sit in data centres.

The phrase “the cloud” can make this sound abstract, but it still depends on real computers, networking, power and storage.

7. Frontend and backend

The frontend is the part of an application a user interacts with: buttons, menus, forms and layouts.

The backend is software working behind the interface. It might manage accounts, databases, files, authentication or AI requests.

8. Runtime

A runtime is the environment in which software actually executes.

Code sitting in a repository is not necessarily doing anything. It needs an appropriate environment in which to run.

Example: asking ChatGPT a question

A simplified sequence looks like this:

You → ChatGPT app → Android → internet → remote infrastructure → AI model → response → your app

This is deliberately simplified. Later lessons will unpack APIs, models, inference, servers and networking separately.

Why this matters for AI

AI is not separate from ordinary computing.

AI systems still need hardware, software, data, runtimes and often networking. AI adds specialised components—particularly trained models—but the underlying computing foundations remain.

If you understand the layers underneath AI, later concepts such as APIs, model hosting, local AI, cloud costs, privacy and deployment become much easier to reason about.
