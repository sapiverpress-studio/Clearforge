What code actually does

Estimated learning time: 8–10 minutes.

Ready to listen. Speed: 1.00×.
Core mental model:
Code is a precise set of instructions. Programs store values, make decisions, repeat work and group reusable behaviour into functions.

1. Code is instruction, not intelligence

A computer program is made from instructions written in a programming language.

The computer does not understand those instructions the way a human understands a sentence. The source code must ultimately be interpreted, compiled or otherwise translated into operations the machine can execute.

Different languages use different syntax, but many share the same underlying ideas: store information, transform it, test conditions, repeat operations and call reusable blocks of behaviour.

2. Statements tell the program to do something

A statement is an instruction in a program.

For example, a statement might assign a value, call a function or make a decision.

Programming languages differ in their exact grammar, so the same idea can look different in Python, JavaScript, Java or another language.

3. Variables give values names

A variable lets a program refer to a value by name.

In JavaScript, this might look like:

let score = 3;

The important idea is not the punctuation. The useful mental model is that the program now has a named value called score whose current value is 3.

Variables can hold different kinds of values, such as numbers, text, true-or-false values, arrays and objects.

4. Data types describe kinds of values

Programs often need to distinguish different kinds of data.

A number such as 25 is different from text such as "25". They may look similar on screen, but software may treat them differently.

A Boolean value represents one of two logical states: true or false.

This distinction becomes important because conditions often evaluate to true or false.

5. Conditions let code choose a path

A conditional tells a program to run different code depending on whether a test is true or false.

if (score >= 4) {
  showMessage("Passed");
} else {
  showMessage("Try again");
}

This does not mean the program has judgement in the human sense. It is following a rule written by the developer.

The program tests a condition, then executes the matching branch.

6. Functions package reusable behaviour

A function is a reusable block of code that performs a task.

Instead of rewriting the same instructions repeatedly, a developer can define them once and call the function whenever that behaviour is needed.

function double(number) {
  return number * 2;
}

Here, number is a parameter. Calling double(4) gives the function the value 4, and the function returns 8.

7. Loops repeat work

A loop lets a program repeat a set of instructions.

If you wanted to process 500 records, you would normally avoid writing the same operation 500 times. A loop can apply the operation repeatedly.

The loop needs rules controlling when repetition starts, continues or stops. Poorly written loop conditions can produce bugs such as an infinite loop.

8. Programming languages are tools, not different universes

Python, JavaScript, Java, C#, Rust and other languages differ in syntax, type systems, runtimes, performance characteristics and intended uses.

But concepts such as values, functions, conditions and repetition appear across many languages.

This is why learning programming concepts is more valuable than memorising one language's punctuation.

Worked example: your Sapiver Learn quiz

When someone taps a quiz answer, JavaScript can read which button was selected, compare its value with the stored correct answer, update the score and change the page.

The code uses several concepts from today's lesson at once.

A variable can store the score. A conditional can decide whether the answer was correct. A function can update the score display. A loop can process all quiz questions when resetting the lesson.

The visible interface is the frontend, while the JavaScript provides behaviour inside that frontend. That connects today's lesson directly to Day 1's application model and Day 2's web concepts.

Why this matters for AI

AI applications still depend on ordinary software.

A model may generate a response, but surrounding code decides when to call the model, what data to send, how to validate inputs, what to display and what should happen next.

Later, when we discuss AI agents and automation, this distinction becomes critical: a language model can propose or generate information, while deterministic code can enforce specific rules and operations.

Key terms

VariableA named reference used to work with a value.

BooleanA logical value that is either true or false.

FunctionA reusable block of behaviour that can be called.
ParameterA named input accepted by a function.
LoopA structure that repeats instructions according to rules.
