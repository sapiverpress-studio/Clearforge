How neural networks learn

Estimated learning time: 8–10 minutes.

Ready to listen. Speed: 1.00×.
Core mental model:
A neural network is a stack of mathematical transformations. Layers combine inputs using learned weights and biases, apply activation functions, and pass results forward. Training adjusts those parameters so outputs better match the objective.

1. Neural networks are model architectures

A neural network is a machine-learning model architecture built from connected computational units arranged in layers.

The name is a loose biological analogy. Modern neural networks are mathematical systems, not digital copies of human brains.

Multiple layers let the model learn useful combinations and nonlinear representations of input data.

2. Layers transform information

A network normally has an input stage, one or more hidden layers and an output layer.

Inputs enter the network, hidden layers transform them, and the output layer produces the prediction or representation needed by the task.

Networks with many stacked layers are commonly described as deep neural networks, which is where the term deep learning comes from.

3. Weights control influence

Inside many layers, each input is multiplied by a learned parameter called a weight.

A weight controls how strongly that input contributes to the next calculation and in which direction.

Large networks can contain huge numbers of learned parameters.

4. Biases shift the calculation

A bias is another learned parameter, added after weighted inputs are combined.

A simplified unit can be thought of as: weighted inputs, plus bias, then an activation function.

Training adjusts these values rather than a developer manually choosing every one.

5. Activation functions add nonlinearity

If every layer only performed linear operations, stacking layers would still behave like one linear transformation.

An activation function introduces a nonlinear transformation so the network can model more complex relationships.

ReLU, short for Rectified Linear Unit, is one widely used activation function.

6. A forward pass produces an output

During a forward pass, data moves through the layers until the network produces an output.

This forward computation is also what a trained network performs during inference.

7. Loss measures error against the objective

During training, a loss function compares the model's output with the training objective and produces a numerical error signal.

Training then needs to determine how changes to the model's parameters would affect that loss.

8. Backpropagation computes gradients

Backpropagation efficiently applies the chain rule from calculus to calculate gradients of the loss with respect to the network's parameters.

An optimiser uses those gradients to update parameters in a direction intended to reduce the loss.

This forward-pass, loss, gradient and update cycle repeats many times during training.

9. Learned representations are distributed

It is usually too simple to imagine one neuron storing one complete concept.

Useful representations can be distributed across many activations and parameters, with different parts of the network contributing to many behaviours.

This matters later for large language models, whose capabilities emerge from very large learned parameter systems.

Worked example: recognising a handwritten digit

Imagine a network trained to recognise handwritten digits.

Pixel values enter as inputs. Hidden layers repeatedly combine and transform them. During training, predictions are compared with correct digit labels, and the weights and biases are adjusted.

After training, a new image can be passed through the network and the output layer can produce scores for digits zero through nine.

The network supplies a prediction. Ordinary software still decides how that prediction is used.

Why this matters for AI

Modern language models are built using neural networks, particularly transformer architectures.

You do not need to calculate backpropagation by hand, but the mental model matters: training adjusts many learned parameters, and inference runs new inputs through the trained network.

That foundation makes the next step — understanding large language models — much easier.
