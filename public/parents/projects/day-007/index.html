Build your own with AI

You do not need to start with code. Copy this prompt and tell AI what you want changed:

Build me a mobile-friendly bag checklist as one standalone HTML file. Let me create several named bags, add and remove custom items, tick items as packed, show progress and reset a list without deleting it. Include optional starter lists and save everything in localStorage. Use no external libraries, explain privacy accurately and add clear instructions for opening the file.

Privacy: Your bag names, items and ticks stay in this browser's local storage. This page does not send them to Sapiver Press or any other service. Clearing browser data will remove them.
